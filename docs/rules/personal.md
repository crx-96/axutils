# 项目个人偏好

本文件只记录用户已确认的 axutils 项目偏好，适用于本仓库及其子包。全局已经生效的沟通、注释、协作和交付规则不在这里重复；编辑器使用方式不作为个人约束。

## 命名与格式

- 新增多词文件一般使用 `kebab-case`，变量和函数使用 `camelCase`，类型和类使用 `PascalCase`。已有公共名称、协议字段及局部稳定命名保持兼容。
- 沿用仓库 Biome 的格式风格；缩进、行宽、引号、分号与尾逗号等具体选项只在 [Biome 配置](../../biome.jsonc)中维护。
- 保留导入整理与对象键排序。具有求值或枚举顺序语义的对象使用有具体原因的局部豁免；包清单使用专用排序，保留条件导出的语义顺序。

## 维护归属

用户明确要求长期保留或调整的项目个人偏好统一维护在本文件。工程契约、目录职责和验证要求留在对应项目规范，可复用操作流程留在项目 Skill；不将一次任务的安排自动转成长期偏好。目录与文件按职责和依赖拆分，具体判断依据见[架构规范](../architecture.md#功能落位与文件拆分)，不另设个人行数或深度限制。
